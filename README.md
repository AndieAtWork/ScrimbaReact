# Scrimba's React Course final projects
I took this course during 2026 to relearn what little I knew of React. It consisted of 6 modules and 6 guided projects.
(The CSS was given to us this time, I must admit :) )
The course's content consisted of:
- The use of props to pass to components
- Conditional rendering
- Applying styles
- Getting info from forms
- useState
- useEffect and dependencies
- useRef
